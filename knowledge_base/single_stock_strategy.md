# 个股基本面×趋势双轮动策略（PEG × 20/60均线 × 相对强度）

> 来自《AI+个股投资策略.pdf》的核心规则重述与标准化（适配AI工作流）；示例标的：英维克（002837）。  
> 目标：将**基本面估值（PEG）**与**趋势过滤（20/60日均线、MACD/RSI）**、**相对强度（个股/基准ETF）**结合，形成可执行、可回测、可量化的**个股策略模块**。

## 1. 策略目标与原则
- **控制回撤**：以 ≤15% 最大回撤为约束的仓位动态管理目标（来源于策略文档的实践目标）。
- **超额收益**：以“年化超基准（如创业板指数）20%”为参考目标（来自策略文档的目标描述）。
- **机械执行**：条件满足即执行；条件不满足即观望/减仓，**避免主观干预**。

## 2. 关键变量与定义
- **PEG（动态）**：使用 Wind/iFind 的**一致预期**数据；不使用主观“未来数据”。
- **趋势过滤**：
  - 价格 > MA20 且 MA20 > MA60（**主条件**）。
  - 辅助条件（三选一）：**MACD 金叉** / **RSI(14) > 50** / **相对强度创 20 日新高**。
- **相对强度（RS）**：RS = 个股收盘价 ÷ 基准ETF收盘价；
  - 基准ETF示例：**515680**（策略文档里的用例，亦可按行业/风格替换为更贴合的ETF）。
  - 触发阈值：RS 创 20 日新高 → 视作“独立强势”的**缓冲条款**。

## 3. 动态仓位表（PEG × 市场风格）
> 直接来自策略文档的执行业务规则，已结构化为表格便于编程。

| PEG 区间           | 市场风格 | 建议仓位 | 解释 |
|---|---|---|---|
| ≤ 0.8             | 任意     | 100%    | 低估+成长匹配 |
| 0.8 < PEG ≤ 1.2   | 牛市     | 80%     | 估值合理（波动率 < 25%） |
| 0.8 < PEG ≤ 1.2   | 熊市     | 60%     | 估值合理（波动率 > 25%） |
| 1.2 < PEG ≤ 1.8   | 牛市     | 50%     | 略高但趋势延续 |
| 1.2 < PEG ≤ 1.8   | 熊市     | 30%     | 仅保留底仓（警惕回调） |
| > 1.8             | 任意     | 10%     | 高估清仓/仅留底仓 |

> 备注：**市场风格与波动率**可由指数（如创业板/万得全A）历史波动率与涨跌判断；建议在AI工作流中统一封装。

## 4. 交易执行与风控
- **入场前置条件**：满足“价格 > MA20 > MA60”且（三选一）辅助条件成立。
- **止损**：**收盘价跌破 MA60 → 市价清仓**（接受 ≤0.5% 滑点）。
- **极端行情**：若开盘跌停/流动性枯竭 → **持续挂单至成交**（接受 ≤1% 滑点）。
- **复盘频率**：
  - **财报后**（每季度）：更新 PEG（Wind/iFind 一致预期）；按表调整**目标仓位**。
  - **每周五 14:55**：检查主条件 + RS/行业ETF；浮盈 ≥15% 上移止损。
  - **每年 12-31**：年度评估，仅在数据支持时对 PEG 区间/均线周期/回撤阈值做**小幅微调**。

## 5. 条件单与日志（落地清单）
- **券商条件单**（示例）：
  1) 触发：收盘价跌破 MA60 → **市价清仓**；  
  2) 触发：**相对强度（RS）创 20 日新高** → 标记“持有”；  
  3) 触发：**开盘跌停** → **持续挂单至成交**（≤1%滑点）。
- **投资日志字段**：日期、PEG数据源、RS值、风格判断、极端行情处理记录、当周操作与原因。

## 6. 与现有脚本和提示词的对接
- **与技术脚本**：《optimized_技术流代码.txt》中的“买0≥2”“Z值≥1.2”“评分>60”等条件，与本策略的**趋势过滤与风险剔除**高度兼容；建议：
  - 将“主条件” 与 “买0≥2” 做**双重确认**以提高胜率；
  - 保留“Z值<1.2”剔除高风险标的；
  - 评分<40 或放量下跌时配合**降仓/卖出**。（详见《二级市场通用技术指标脚本》）
- **与提示词**：新增“**策略执行提示词（PEG×趋势×RS）**”，统一输出**目标仓位**、**动作**、**风险与日志要点**，详见 `ai_analysis_prompts.md`。

## 7. 回测与参数
- 建议将 **MA(20/60)**、**RS 观察窗（20日）**、**RS 基准ETF**、**PEG 分段阈值** 做成**可调参数**，支持 Walk-Forward 与样本外验证。
- 关键评估指标：**最大回撤、Calmar、信息比率、持仓胜率、盈亏比、换手**。
