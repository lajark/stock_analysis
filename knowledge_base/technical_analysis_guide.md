# A股技术分析知识库

> 专业的A股技术分析、投资策略和风险评估知识库
> 适用于AI股票分析助手的核心知识体系

## 📊 1. 技术指标深度解读

### 1.1 MACD指标 (指数平滑移动平均线)

**基本概念**
- **计算公式**: MACD = EMA(12) - EMA(26)
- **信号线**: Signal = EMA(9) of MACD
- **柱状图**: Histogram = MACD - Signal

**解读方法**
- **金叉信号**: MACD > Signal，且MACD > 0，表示上升趋势确认
- **死叉信号**: MACD < Signal，且MACD < 0，表示下降趋势确认
- **零轴金叉**: MACD和Signal都在零轴上方金叉，强势买入信号
- **零轴死叉**: MACD和Signal都在零轴下方死叉，强势卖出信号

**背离判断**
- **顶背离**: 价格创新高，MACD未创新高，预示可能见顶
- **底背离**: 价格创新低，MACD未创新低，预示可能见底

**实战要点**
- MACD在零轴上方运行表示强势，下方运行表示弱势
- 柱状图由负转正，表示空头转多头
- 柱状图由正转负，表示多头转空头

### 1.2 RSI指标 (相对强弱指数)

**基本概念**
- **计算公式**: RSI = 100 - (100 / (1 + RS))
- **RS计算**: RS = 平均上涨点数 / 平均下跌点数
- **标准周期**: 14天

**解读方法**
- **超买区间**: RSI > 70，表示可能见顶，注意回调风险
- **超卖区间**: RSI < 30，表示可能见底，注意反弹机会
- **中性区间**: 30 ≤ RSI ≤ 70，正常波动区间
- **极端超买**: RSI > 80，严重超买，回调概率很大
- **极端超卖**: RSI < 20，严重超卖，反弹概率很大

**背离判断**
- **顶背离**: 价格创新高，RSI未创新高，看跌信号
- **底背离**: 价格创新低，RSI未创新低，看涨信号

**实战要点**
- RSI在50以上表示强势，50以下表示弱势
- RSI突破50是重要的趋势转换信号
- 在震荡市场中，RSI的背离信号更可靠

### 1.3 KDJ指标 (随机指标)

**基本概念**
- **K值**: 快速随机线，敏感度最高，反应最快
- **D值**: 慢速随机线，趋势判断，相对稳定
- **J值**: J = 3K - 2D，波动最快，适合短线

**解读方法**
- **金叉信号**: K > D，且K < 80，买入信号
- **死叉信号**: K < D，且K > 20，卖出信号
- **超买区间**: K > 80，D > 80，注意回调风险
- **超卖区间**: K < 20，D < 20，注意反弹机会

**实战要点**
- J值波动最快，适合做短线参考
- D值波动最慢，更适合中期趋势判断
- KDJ三线同时向上，强势确认
- KDJ三线同时向下，弱势确认

### 1.4 布林带指标 (Bollinger Bands)

**基本概念**
- **中轨**: N日移动平均线 (通常20日)
- **上轨**: 中轨 + K倍标准差 (通常K=2)
- **下轨**: 中轨 - K倍标准差 (通常K=2)
- **带宽**: 上轨 - 下轨，反映波动率

**解读方法**
- **价格位置**: 
  - 价格触及上轨 = 可能超买
  - 价格触及下轨 = 可能超卖
  - 价格在中轨附近 = 正常波动
- **通道形态**:
  - 通道收窄 = 波动率降低，可能蓄势
  - 通道扩张 = 波动率增加，趋势明确
- **突破判断**:
  - 收盘价突破上轨 = 强势突破
  - 收盘价突破下轨 = 弱势突破

**实战要点**
- 布林带收窄往往是大行情前的"蓄势"
- 价格在布林带内上下窄幅震荡时，建议耐心等待突破方向
- 突破后迅速回落，往往是假突破；持续停留在轨道外，则可能是真突破

### 1.5 成交量指标

**基本概念**
- **量增价涨**: 买方强势，多头趋势健康
- **量增价跌**: 卖方压力较大，警惕反转或继续下跌
- **量缩价稳**: 市场观望情绪浓厚，预示后续波动可能加大
- **量价背离**: 价格创新高但成交量萎缩，或价格创新低但成交量放大

**解读方法**
- **放量突破**: 价格突破重要阻力位，成交量明显放大，突破有效
- **缩量回调**: 价格回调但成交量萎缩，可能是正常调整
- **放量下跌**: 价格下跌且成交量放大，空头强势
- **地量见底**: 成交量极度萎缩，可能见底

## 📈 2. 市场分析框架

### 2.1 趋势分析

**时间框架划分**
- **短期趋势**: 5-10日移动平均线，适合短线操作
- **中期趋势**: 20-30日移动平均线，适合波段操作
- **长期趋势**: 60-120日移动平均线，适合长线投资

**趋势确认标准**
- **上升趋势**: 价格在主要均线上方，均线向上发散
- **下降趋势**: 价格在主要均线下方，均线向下发散
- **震荡趋势**: 价格在均线附近波动，均线走平

**趋势转换信号**
- **趋势破坏**: 价格跌破主要均线，且均线开始向下
- **趋势确认**: 价格突破主要均线，且均线开始向上
- **假突破**: 价格突破均线但很快回落，成交量不配合

### 2.2 支撑阻力分析

**支撑位识别**
- **历史低点**: 前期重要低点
- **整数关口**: 整数价位，如10元、20元等
- **技术指标支撑**: 布林带下轨、前期低点连线
- **成交量支撑**: 放量上涨的起始价位

**阻力位识别**
- **历史高点**: 前期重要高点
- **整数关口**: 整数价位
- **技术指标阻力**: 布林带上轨、前期高点连线
- **成交量阻力**: 放量下跌的起始价位

**突破确认标准**
- **价格突破**: 收盘价突破重要价位
- **成交量配合**: 突破时成交量明显放大
- **时间确认**: 连续3天以上站稳突破位
- **回踩确认**: 突破后回踩但不跌破突破位

### 2.3 市场情绪分析

**情绪指标**
- **恐慌贪婪指数**: 综合多个指标的市场情绪指标
- **资金流向**: 主力资金净流入/流出
- **换手率**: 反映市场活跃度
- **涨跌停数量**: 反映市场极端情绪

**情绪周期**
- **恐慌期**: 市场极度悲观，可能是底部信号
- **犹豫期**: 市场观望情绪浓厚，等待方向
- **乐观期**: 市场情绪好转，但需警惕过热
- **狂热期**: 市场极度乐观，可能是顶部信号

## 🎯 3. 投资策略模板

### 3.1 买入条件

**技术指标共振**
- 至少3个技术指标显示买入信号
- 主要指标方向一致，无重大背离
- 指标信号强度适中，避免极端值

**趋势确认**
- 价格在主要均线上方运行
- 均线系统向上发散
- 短期趋势与中期趋势一致

**成交量配合**
- 放量突破重要阻力位
- 回调时成交量萎缩
- 上涨时成交量温和放大

**风险控制**
- 设置明确的止损位
- 控制单只股票仓位不超过总资金的10%
- 避免在极端市场情绪下重仓

### 3.2 卖出条件

**技术指标背离**
- 多个技术指标显示卖出信号
- 出现明显的顶背离信号
- 指标从超买区间回落

**趋势破坏**
- 价格跌破主要均线
- 均线系统开始向下发散
- 短期趋势与中期趋势背离

**成交量异常**
- 放量下跌，空头强势
- 上涨时成交量萎缩，上涨乏力
- 突破失败，成交量不配合

**止盈止损**
- 达到预设的目标价位
- 触及止损位，控制损失
- 基本面发生重大变化

### 3.3 观望条件

**信号矛盾**
- 不同技术指标给出相反信号
- 短期与中期趋势不一致
- 成交量与价格走势不匹配

**趋势不明**
- 价格在均线附近震荡
- 技术指标处于中性区间
- 市场缺乏明确方向

**成交量低迷**
- 市场参与度不高
- 成交量持续萎缩
- 缺乏明显的资金流入流出

**等待确认**
- 等待更明确的技术信号
- 等待基本面信息确认
- 等待市场情绪稳定

## ⚠️ 4. 风险评估标准

### 4.1 风险等级划分

**低风险特征**
- 技术指标良好，无重大背离
- 趋势明确，价格在均线上方
- 成交量正常，无异常放大
- 基本面稳定，无重大利空

**中风险特征**
- 部分技术指标异常
- 趋势不明，价格在均线附近
- 成交量波动较大
- 基本面存在不确定性

**高风险特征**
- 多个技术指标恶化
- 趋势破坏，价格跌破均线
- 成交量异常放大或萎缩
- 基本面存在重大风险

### 4.2 风险控制措施

**仓位控制**
- 低风险时：单只股票仓位可达10%
- 中风险时：单只股票仓位控制在5-8%
- 高风险时：单只股票仓位控制在3-5%

**止损设置**
- 根据股票波动率设置止损位
- 一般止损位设置在支撑位下方
- 止损幅度控制在5-10%

**分散投资**
- 避免单一股票过度集中
- 行业分散，避免行业风险
- 风格分散，平衡成长和价值

**定期评估**
- 每周评估持仓风险
- 根据市场变化调整策略
- 及时止损止盈

## 📋 5. A股市场特点

### 5.1 交易规则

**涨跌停限制**
- 主板：±10%
- 创业板：±20%
- 科创板：±20%

**交易时间**
- 上午：9:30-11:30
- 下午：13:00-15:00
- 集合竞价：9:15-9:25

**T+1交易**
- 当日买入，次日可卖出
- 当日卖出，资金当日可用

### 5.2 市场特征

**政策敏感**
- 政策变化对市场影响较大
- 需要关注政策动向
- 政策利好/利空直接影响股价

**情绪化特征**
- 投资者情绪波动较大
- 容易出现过度反应
- 情绪指标对市场影响显著

**板块轮动**
- 不同板块轮番表现
- 热点切换频繁
- 需要关注板块轮动规律

**季节性特征**
- 存在明显的季节性特征
- 如"春季行情"、"秋季调整"
- 需要结合季节性因素分析

### 1.6 相对强度与20/60均线过滤（与PEG策略的衔接）

**相对强度（RS）**：RS = 个股收盘价 ÷ 基准ETF收盘价（示例：515680）。  
- **用途**：当 RS 创 20 日新高，视作“独立强势”的缓冲条款，可与 MACD/RSI 互为替代的趋势辅助条件。  
- **可调参数**：观察窗（默认20日）、基准ETF（行业/风格可替换）。

**20/60均线过滤**：价格 > MA20 且 MA20 > MA60 作为**趋势主条件**，可配合：  
- MACD金叉 / RSI(14)>50 / RS创20日新高（三选一）作为**辅助条件**。

**与财务Z-Score/评分体系联动**：
- 保留“Z值<1.2”剔除高风险标的；
- 评分>60再入场可提高胜率，评分<40考虑降仓/退出。
