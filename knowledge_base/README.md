# 知识库来源与使用说明

本目录保存供本地分析和 LLM 报告生成使用的结构化 Markdown 知识。运行时只读取与分析模式
相关的少量段落，不把原始资料或完整历史行情发送给 LLM。

## 内容来源

- `technical_analysis_guide.md`、`market_patterns.md`、`ai_analysis_prompts.md`：项目知识库内容。
- `single_stock_strategy.md`：基于项目作者本人编辑的《AI+个股投资策略.pdf》进行结构化、通用化改写。
- `investment_cases.md` 中“策略执行 - 英维克”段落：提炼自上述作者自有文档。

项目作者已于 2026-08-14 确认《AI+个股投资策略.pdf》为本人编辑的文档，不涉及第三方授权
限制；上述 Markdown 派生内容随本项目公开分发并适用项目 `LICENSE`。

## 为什么不包含原始 PDF

原始 PDF 保留在工作区根目录作为本地来源底稿，不复制到本目录，也不进入 Git 或 Windows
安装包，原因如下：

1. PDF 内容已经由 Markdown 完整覆盖，重复分发没有运行价值。
2. Markdown 更适合按章节检索，能减少无关版式和过时日期进入 LLM 上下文。
3. 原文包含特定标的和阶段性执行示例，知识库版本需要保持方法论表达，并结合当前数据计算使用。
4. 保留本地底稿与公开派生内容分离，符合 `DISTRIBUTION_POLICY.md` 的最小必要分发原则。

## 使用边界

- 策略阈值和案例仅用于分析框架参考，不是自动交易指令。
- 任何目标收益、回撤或历史涨幅描述均不代表未来表现。
- 报告必须结合程序当次获取并在本地计算的数据，不得让 LLM 用知识库内容补造缺失数据。
- 新增外部资料前必须记录来源和许可；来源不明确时不得公开分发。
